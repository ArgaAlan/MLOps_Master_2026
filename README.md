## 🗂️ Estructura del Repositorio

El repositorio está organizado por actividades y entregas modulares:

```text
MLOps_Master_2026/
├── actividad_2_experimentacion_mlflow/   <- Código, scripts y dataset de la Actividad 2
│   ├── train.py                          <- Script modular y parametrizado (CLI)
│   ├── ejecutar_experimentos.sh          <- Ejecución automatizada de 5 corridas
│   ├── requirements.txt                  <- Dependencias con versiones fijadas
│   ├── notebook_mlops_baseline.ipynb     <- Notebook de exploración de datos (EDA)
│   ├── data/                             <- Dataset Breast Cancer Wisconsin
│   └── README.md                         <- Documentación técnica de ejecución
│
└── documentacion_actividad_2/            <- Documentación, reporte y evidencias
    ├── README.md                         <- Guía de la documentación
    ├── reporte_analisis.md               <- Reporte técnico formal (Markdown)
    ├── reporte_analisis.txt              <- Reporte técnico formal (Texto plano)
    └── capturas_mlflow/                  <- Capturas de pantalla de la interfaz de MLflow
        ├── SS 1.png
        ├── SS comparativa 1.png
        ├── SS comparativa 2.png
        └── SS Corrida_4_solver_liblinear.png
```
